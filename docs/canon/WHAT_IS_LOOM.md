# WHAT IS LOOM

> 定盘星文档(2026-07-09)。迷茫时翻开这一页。
> 由三轮 grounded 研究收敛而成:商业结局盘点、"服务判断"的具体化、Duolingo/Anki 深挖。
> 写在 owner 从"我不知道 LOOM 该是什么"走到一个证据充分、可落地的答案之后。

---

## 一、LOOM 是什么

名字自己说了。**Loom = 织布机**:把互不相干的线,织成一块**看得见在长**的布。**Loom(动词)= 渐渐成形、赫然耸现**:远处模糊的东西,随着你走近、随着它长大,轮廓越来越清楚,直到有一天立在你面前。

> **LOOM 是一台把一个人每天读到、想到的零散线头,织成一块看得见的布的机器——织得够久,布里会浮现出一个人影,那就是你。**

- 每天的材料是**纬线**:读的一章、划的一段、冒出来的一个疑问
- 你的长期结构是**经线**:你在学的领域、你追问的问题——绷在那里,不随日常晃动
- 产品的核心画面是**布**:一个你能随时后退一步、看到它真实在长的整体
- 织到最后,布够大了,布里站出来一个你——**Digital Me**

它和 owner 早已定下的东西是同一个灵魂:**吸收 → 系统化 → 成为**,即**读厚 → 读薄 → 融会贯通**。那 47 篇 wiki 就是第一匹手工织出来的布。

---

## 二、它的唯一一份工作

把"你读过的东西"变成"你的知识",再变成"你自己"。

最终呈现永远是**一本书**(结构清晰 + 专业排版),**不是收件箱**。收件箱是没消化的线头堆;书是判断过、结构化过的布。验收测试:**盖住 chrome,它读起来像不像你的 wiki 文章?**

---

## 三、护城河在哪(以及不在哪)

一个代表你的 AI 代理,拆开看就是:系统提示 + 检索到的上下文 + 工具。所以"你的知识变成代理"**在运行时确实只是个上下文问题**——而上下文正在被 RAG / 长窗口 / MCP / 平台(苹果、Google、微软)快速商品化。

**但"上下文"糊住了两样不同的东西:**

- **你的数据**(读过、录过的一切)= 上下文问题 = 商品。谁都能检索。
- **你的知识**(蒸馏过、你背书过、有结构、交叉连接过的版本)= **不是躺在那里等检索的,得被"造"出来。**

模型喂你的原始输入,**分不清哪些是你相信的、哪些只是你碰到过的**。Rewind"记录你的一切"死掉,正因为"全记下来"产出的是噪音。**Garbage in, garbage out——换成了 you。**

所以护城河**不在 agent**(商品),**不在检索**(商品),**在那一堆被你背书过、结构化过的个人知识,以及那台让"养它"值得做的机器**——也就是工作台。这正是 owner 建造顺序对的原因:**Digital Me 排第三,恰恰因为它"只是上下文";护城河上移到了制造上下文的工作台。**

产物不只是知识内容,是一份**判断轨迹**(你写的 claim、留的 open question、画的连线)——**判断比内容更难商品化,平台吸得走你的数据、吸不走你的判断轨迹。这才是让代理"是你"的东西。**

**看空理由(必须记住):** 也许模型够聪明,把原始堆现场蒸馏就够用,"养"是白费力。LOOM 押的注是:存在一道模型规模填不平的**质量/信任/判断的沟**——你检索不到一个从没形成过的信念;养的过程本身就是学习。**对冲:工作台哪怕在 agent 层归零时,仍作为学习工具独立值钱(Readwise/Obsidian 已证明)。agent 是 upside,不是地基。**

## 四、唯一的设计法则

AI 时代,**执行**变便宜(写、查、总结、起草)。稀缺的是**判断、品味、意识**——它们不可外包,一旦外包就不再是"你的"。

工具因此分两种:

- **自动化工具**:替你做。注定商品化,而且**会萎缩掉那个正在变稀缺的官能**——你让 AI 替你读,你就永远长不出判断力。
- **器物(instrument)**:磨快并服务**你的**判断。不替你读,让你读得更深。

**但研究给出一条硬纠正**(推翻了"friction is the product" 的粗糙版):市场从不奖励"要求你思考"的工具——每个纯"逼我思考"品类都有留存悬崖(Anki 两周弃、PKM 坟场、OpenAI 杀掉 Study Mode)。用户揭示性偏好压倒性地选"替我做",哪怕被告知质量更低。

关键是**两根轴要分开**:

|  | **省力启动** | 费力启动 |
|---|---|---|
| **服务判断** | ✅ 赢家全在这格(ChatGPT Asking · Duolingo · Readwise · Are.na) | ☠️ 裸 Anki / 裸 Khanmigo / PKM 坟场 |
| 替代判断 | 💰 商业赢家,但商品化 + 让用户萎缩(陷阱) | — |

**精确的和解:判断里的费劲要留住**(回忆、写自己的话——不可外包的价值);**启动的费劲必须归零**(决定去做的阻力、归档杂役)。Duolingo 保留费脑、把激活能量降到接近零,赢了 Anki 约 1000 倍。

> **第一性原理:LOOM 不要求你思考,它让你自己的思考省力地复利。AI 在其中只逼问、不替代(苏格拉底式,不是神谕式)。**

设计剃刀:**每个功能问一句——它行使用户的判断,还是替代它?** 替代 = 执行功能,商品化 + 萎缩用户。行使 = 服务稀缺官能。只建后者。但注意:不自动化是**必要不充分**——一个只加仪式摩擦却没磨快任何东西的工具,是**摩擦剧场**,比自动化工具更糟。

## 五、坟场:不要建什么(研究验证的红线)

- **永远不要在门口卖"effort"**——不要"专注模式/逼你思考/拒绝帮你"的开关或话术。
- **不要把"拒绝回答"做成看得见的 UI**——Khanmigo 裸 Socratic 被 Sal Khan 亲口称 "non-event",3 周掉 60%,小孩霸凌它要答案。
- **不碰矛盾检测**("你这里说 X 那里说 Y")——整套研究里最清楚的"零证据"发现,无人做成过,且当前 AI 更可能**捏造**矛盾。
- **不造神谕/自动洞察**——Mem 融了 $29M(含 OpenAI)也没买到留存,推倒重建。"学会你持续看重什么、预测你会喜欢的"——没有任何被爱的产品做成过。
- **不做可见的 overdue/due 计数、不做累积债务、不做 XP/排行榜/hearts/社交比较、不做内疚营销**(见 §六)。
- **不宣传"90% 留存/永不遗忘"**——诚实的价值主张是兑换率:"几分钟复习买几周持久记忆"。

## 六、第一个具体功能:Review 楔子

把"服务判断"砍到最小、可日用、能复利的**唯一原子动作**,而且它**专属 LOOM**:

> **在一条你自己 anchor 过的源文引文上,翻面之前,先重建你当初的理解。**

这是 **retrieval practice + generation effect**(学习科学复制最稳的结论,d≈0.4-0.8),作用在**你自己作者化过的材料**上,判断 100% 留在用户手里。

**形态:**
1. 在阅读器把引文 anchor 进笔记时,顺手写一句**自己的话**(为什么重要/我读到什么)——必须你写,AI 不代笔(生成效应)。
2. 每天一屏,LOOM 推回那条源文引文,**把你自己那句话盖住**,问"你当初从这里读到了什么?"
3. 脑内重建 → 揭开对照 → 3 档自评 → 间隔扩大。
4. 揭开后**一键跳回源文原位**(`loom://anchor` 已支持)——resurface 不只是提词,是**通向领土的门**(Readwise 做不到、LOOM 独有)。

### 设计规格(向 Duolingo 偷习惯,向 Anki 偷别死)

**最承重的一条:恒定份额 vs 累积债务。** Duolingo 每日负荷恒定,Anki 每日负荷=欠下的所有天数之和(可见的逾期数=厌恶刺激→关 app→债务再涨,doom loop)。Duolingo 自己 2022 年**亲手删掉**了它的衰减模型。

| 参数 | 拍板值 | 为什么 |
|---|---|---|
| 每日份额 | 固定 5-7,上限 ~15,**输出端硬封顶,与到期量解耦** | Anki 头号死因 |
| 累积债务 | **绝不**。无 rollover,无可见 overdue,未完成午夜过期 | doom loop |
| streak | **用,但 forgiving**(auto-freeze/预发 grace);**唯一条件:必须一次真实 recall 才算数,不可被 trivial 动作刷** | Duolingo 7 天拐点 + anti-theater |
| 算法 | **不用完整 FSRS**(单用户早期喂不饱),用**简化半衰期 + recall 概率优先**(阈值 50% 成候选),后期再升 FSRS | 单用户合身 |
| 盖住 | **默认盖住**(active recall = 楔子的科学承重点;这是与 Duolingo recognition 相反的**那一个轴**,必须死守) | 生成效应 |
| 自评 | **3 档**(没想起/勉强/稳),不用 Anki 4 档 | 减决策摩擦 |
| 优先级 | **激进重浮现答错/不确定项**,答对的拉长退场 | 答错项两月陡降到 56% |
| 提醒 | 同时段仪式 cue + 傍晚 streak 救援;calm、English-only、无内疚 | Duolingo 两枪 + copy 铁律 |

**判据(anti-theater):** 如果 streak 能在不做一次真实提取的情况下增长,它就是 engagement theater,删掉。**成功指标是"用户真的记得他的材料"(可能意味着更少 app 时间),不是 reviews-completed。设计那个即使泄漏出去你也会骄傲的指标。**

**Anki 死法 → LOOM 结构性优势:** Anki 造卡摩擦占一次 session 的 52%——而 LOOM 的复习项**从你自己的笔记派生**,造卡摩擦几乎为零,同时保留"从我学过的东西里来"的质量。**两头的好处都拿到,两头的死法都避开。**

**前沿钻石(Quantum Country):** 最著名的"复习嵌进阅读"实验,已投入读者里只有 ~10% 复习过哪怕一次。**算法从不是难点,"让人回来"才是。LOOM 的优势不是"嵌入=有人用",是复习活在一个你本来每天就打开的工具里(你自己的笔记)。首次复习完成 = 北极星激活指标。**

### 定位:一个空的交叉点(Kinnu 研究 2026-07-09 确认)

把竞品摆到两根轴上,有一个没人占的格子——**「你自己捕获的引文 × 主动回忆(非辨认) × spaced」**:Anki 做 recall 但卡靠你写;Kinnu 做 spaced 但在**别人**内容上的 recognition(MCQ);Readwise 捞你自己的材料但被动重读。**楔子踩的正是这个空格,而 Kinnu 结构性到不了(它只认识自己写好的 pathway)。** Kinnu 自己 40 个实验的数据反过来钉死了红线:图谱类题型是最弱干预(+33%),而费力回忆 +66%、prose 质量 +69%、priming +70%——**学习增益来自费力回忆和内容质量,不来自知识图**(它自己否掉了自己的卖点)。Kinnu 商业上没成(3 年估值没动、连环 pivot 逃向考证 deadline)。

**可 absorb 的三样表层便利(都指向你自己的 quote,不动摇楔子):** ① 单一 "Smart Session" 一键入口(组装今日 new+due,契合无累积债务)· ② "At-Risk of Forgetting" 掌握热力图(指向你自己的 quote 池)· ③ open-ended "Why/How" 提示 + priming(preview/summary)——这是 Kinnu 数据里最强杠杆,而"用你自己的话重建"正是楔子已在做的,Kinnu 只是从反面确认它选对了。

### ⚠️ 楔子必须自己守的一条(Kinnu 帮不上的真风险)

价值在**回忆这个动作**,不在"做卡"这个动作:self-generated question 打败重读,但**打不过纯 retrieval practice**。所以 **hide→retrieve→reveal 必须强制**——一旦退化成"重读/重高亮你的 quote",收益基本蒸发。且 **illusion of competence 照样在**:盖住自己写的句子重建出来,也可能只训练了对**那句话**的表层记忆。抵抗:偶尔**换个语境提问**(而非原样复述),逼出**迁移(transfer)**——这是判断"真学到"vs"背了自己那句话"的唯一硬信号。

## 七、商业形态:做 Anki,不做 Duolingo

对一个人,这两条路只有一条可达。

- **Duolingo 路**:$183M VC + growth 组织 + 几千万 DAU 转 ~10% 付费才凑出 $1B。**追它是范畴错误。** 中间层模仿者(Quizlet 付费墙反噬、Memrise 砍 UGC)都在转型时死掉。
- **Anki 路(合身)**:一个开发者、19 年、零 VC、零 marketing、单个 $25 native app 养一个免费生态、据估 ~$700K/月。留存来自**高痛点窄众里的真实学习产出**,不是 streak 内疚。

> **天花板是一个几百万美元/年、近乎纯利、可持续十年的一人生意——VC 看不见,却能改变一个 solo builder 的人生。**

具体:native macOS **一次性买断**(或低订阅 + 终身层)。depth 和 local-first 是护城河,**永远别为了"看起来大众化"把它磨平**(Memrise 就是这么死的)。**先服务好一个人——那个密集 PDF 的研究生,就是 owner 自己。**

## 八、怎么知道它成了 / 假了(诚实指标)

- ✅ **今天复习过的人,明天回不回来复习**(状态转移,不是虚荣总量)——唯一北极星。
- ❌ **streak 长但自评/recall 不涨** = "1000 天 streak 点不了咖啡"的 LOOM 版 = 反目标。
- ❌ **day-3 / day-14 悬崖**(Anki 经典 quit 点)——自己 instrument。
- ❌ **backlog 悄悄膨胀 + 用户 drift**(forgiving 模型的诚实代价)。
- ❌❌ **最硬的证伪:owner 自己在没有外部督促下,不再每天回来用它。** 单用户工具没有比这更真的信号。
