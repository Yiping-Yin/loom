## 一页速读

LOOM = **理解"硬东西"的反-ChatGPT**。当 AI 把"执行"和"开始理解"打到接近免费,唯一稀缺、抄不走的退回到**人的判断力**。LOOM 不让你消费答案,而是**逼你费力地下判断**,过程顺手把判断**捕获成专有数据**,攒成一个**像你一样思考的 agent**。
**Day-one 卖的是**"你理解的东西不蒸发、归你、会复利";**Endgame 是**"它变成你"。
**唯一那道生死闸是留存**;学习本质是维生素;**几乎没人自愿选费力而非无摩擦 GPT**——所以真实用户不是"学习者",是"**很快要为一个查不到答案的硬判断负责的人**"。**还没答的三个 make-or-break 缺口在第四块。**

## 一、产品意愿 / Vision

**时代前提** 【趋势有据;"判断力是唯一稀缺"是定位赌注】:AI 把"执行"和"开始理解"都打到接近免费;稀缺、值钱、抄不走的那层,退回到**人的判断 / 品味(判断力)**。人从"执行者"变成"**思考、品味、想象的决策架构师**"。

**一句话** 【定位】:LOOM 是**理解"硬东西"的反-ChatGPT**——你不在这**消费答案**,而是做 AI 替不了你的事:**费力地下判断**;而这个过程顺手把你的判断**捕获成数据**,攒成一个**像你一样思考的 agent**。

**靠排除来定义** 【定位】:
- **不是 Notion / Obsidian**——那是"收集材料"。
- **不是 Anki**——那是"背孤立的卡"。
- **不是"先建一个 AI 分身"**——LOOM 先让你**真懂**,agent 是**自己掉出来**的副产品,不是第一天先做分身。

**Power of Effort(差异化核心,双刃)**:
- **(a) 教学侧——费力才有理解** 【有证据】:费力的提取 / 重构才产生真正的理解(desirable difficulty / retrieval practice,是学习科学里最稳的发现之一;Bjork,Roediger & Karpicke)。去掉费力,就没有理解。
- **(b) 价值侧——费力才不廉价** 【定位赌注·非实证】:手工 / 费力让东西值钱(奢侈品、高定逻辑)。**LOOM = crafted / 费力,正对着 cheap prompting。**
- **横贯隐喻**:**AI 是织机,不是织工**——抹掉浪费的力(找、整理、排版),保留甚至**强制**有产出的力(提取、重构、下判断)。

## 二、架构 / Architecture

**三层**:
1. **捕获层 · The Loop** —— 高频费力引擎;你在这把硬东西搞懂,同时判断被结构化逼出、捕获。(原"工作台"升级:重心从"吸收知识"→"逼出并捕获判断"。)
2. **判断数据层 · Judgment Data** —— 随时间累积的、结构化的**专有判断数据 = 独特护城河**。(原"Wiki"升级:不只系统化知识,是编码下来的你的判断 / 品味。)
3. **分身层 · Digital Me / Agent** —— 由判断数据生成、代表你、按你品味行动、帮你和更强的模型交互。(原"Digital Me"落地:从"知识展现"→"由判断生成的 agent"。)

**核心回路(一次 session,具体到能一分钟演示)** 【回路结构=设计;能否逼出判断=假设·未证】:
1. **带一个硬东西进来**——一段论文 / 一个技术方向 / 一份条款。
2. **AI 先不给答案,逼你先表态**("你觉得这对不对?关键在哪?")——【捕获 + desirable difficulty】。
3. **AI 当对抗性陪练,不当神谕**(实时语音 / 文字):质疑、反驳、举反例,而不是替你总结。
4. **你随手标**:哪些承重 / 哪些兔子洞 / 接受 / 否定 / 怎么用——**这一标一选,就是一条 `JudgmentUnit` = 专有数据**。
5. **你用自己的话重构**;LOOM 把它**织成一页 crafted、归你的成品**(不是聊天记录)。
6. **累积 → 判断数据 → 你的 agent**。

**一条"判断"作为数据长什么样** 【假设·未证】:
```
JudgmentUnit {
  source:       遇到的硬材料 / 主张
  你的裁决:     认同 / 否定 / "对,但仅在 X 下" / 重构
  你留下的:     你判定为承重的
  你砍掉的:     你判定为噪音 / 兔子洞
  你的重构:     用你自己的话再表达
  应用 / 边界:  你会怎么用、它在哪失效
  置信度 + 理由 、时间、领域
}
```
**和 ChatGPT memory 的根本区别**(必须真做出来,见第四块坑1):memory 是从闲聊里**被动抽取**的事实;JudgmentUnit 是**被主动逼出的、结构化的立场**——关于"**你怎么想**"的带标签数据,不是"你说过什么"。

**横贯原则**:Power of Effort;**数据所有权**(判断数据归你、markdown-owned、可导出)【定位/工程】;**反平台**——平台只能优化"平均用户",LOOM 优化"**这一个人**",这是平台结构上不会做的【定位赌注】。

## 三、发展 / Roadmap

- **Day-one 产品 = 那个费力理解回路**:卖点是"**你理解的东西不蒸发、归你、会复利**"。具体、可建,potential 是 **Anki 式一人生意**【小而美有先例·有证据;LOOM 能达到=假设】。**这是现在要建、要 pitch 的东西。**
- **Endgame = 它变成你**:累积的**判断轨迹**(你真懂过、亲手织过的,不是原始数据)长成一个真正是你的 agent。是**复利方向,不是第一天卖的**【假设·未证】。
- **顺序别倒**:先卖"**读的东西终于留得住**"(广钩子),让"成为你"作复利方向。倒过来先卖分身 = 冷启动死。
- **立刻的下一步 = 验证,不是先建** 【纪律】:找 **5–10 个真人**(见第四块"谁会用")看他们**会不会真走这个费力回路、会不会真回来(留存)**。**零代码**。回来=真;不回来=维生素。

## 四、核心问题的诚实回答 / Core Questions

### 1. 有没有商业价值?

**留存是唯一那道闸** 【有证据】。**学习本质是维生素**(Kinnu 免费+证书=承认 WTP 低;PKM/auto-connect 坟场 Mem/Roam/Napkin 为证)【有证据】。活下来的靠**外部逼迫**(Anki=考试)或**大众游戏化习惯**(Duolingo)——**两者都不易搬到 LOOM**【有证据 + 判断】。自学者侧顶多**小而美**(Obsidian / Readwise 级)【有证据】;**专业侧钱大 10–100 倍,但买的是"权威、可免责的答案",不是"学会"**(UpToDate / Bloomberg / Harvey / OpenEvidence)【有证据】。→ 有价值,但**默认是小而美,且必须过留存关**。

### 2. 谁会用?

**自愿地,几乎没人会选"费力"而不选无摩擦的 GPT——这是费力工具的共同死法** 【有证据·判断】。**唯一会选的,是有 forcing function 的人**:判断错**代价大** + 判断**很快要摆到会看穿浅薄的人面前** + 那件事**没有权威答案可抄、只有判断**。具体:
- **投委会(IC)前的投资人**、**押一个技术方向的创始人**、**答辩前的研究者**、**马上要讲 / pitch 一个硬东西的人**。

**用户定义 = "很快要为一个硬判断负责、又查不到答案的人",不是"学习者"** 【定位;该人群是否真会采纳+留存=假设·未证】。

### 3. 为什么不顺手问 GPT?（最不舒服、必须诚实）

- **诚实认**:LOOM **没有任何 GPT 没有的模型能力**;内核就是通用大模型,**LOOM 是外面那层 harness**【有证据】。
- **但每个 AI 产品都是 harness**(Cursor / Harvey / Perplexity 都"只是用"模型):**产品不是模型,是为一件具体活优化的 harness**【有证据】。
- **LOOM 比 Cursor 弱的地方** 【判断】:Cursor 给你**急着要的东西**(能跑的代码);LOOM 给的是"**费力 / 自律**",**逆着 GPT 的无摩擦爽感** → 会**塌回那个窄人群**。
- **GPT 唯一不易抄的,是"累积的、归你的判断轨迹 → 你的 agent"**——但那是 **Endgame,随 GPT memory 变强而贬值,非 day-1**【有证据·趋势】。
- **底线**:**没有能力护城河,只有软的"自律 + 数据"harness**;要赢"顺手问 GPT",**只能在一个走投无路的人身上做到 10 倍好**【判断/假设·未证】。

### 4. Moral hazard（双用,必须写进设计)

- **叙事** 【定位赌注】:AI 替你思考 = 一份"**不懂也没关系**"的保险,人人外包思考直到掏空自己;LOOM 的 power of effort 把**代价加回去**——*"AI 在制造一代不会自己思考的人,LOOM 是你把判断力留在手里的地方。"*
- **设计铁律** 【原则】:**LOOM 自己的 agent 一旦替你判断,就会制造它要治的那个风险**。所以**人必须始终留在费力回路里,agent 是镜子 / 放大器,不是替身**。这条不能违反,否则 LOOM 变成它批判的东西。

### 5. 三个 make-or-break 缺口（还没答,必须答——这是全文最重要的一节）

1. **一条判断怎么变成比 GPT memory 更值钱的数据?什么机制专门逼出"你的判断"而非又一堆聊天记录?** —— **生死坑** 【假设·未证】。打不过平台自带 memory,整套 thesis 塌。
2. **agent 替谁、干什么、凭什么有人付钱?** 【假设·未证】。不回答,判断护城河只是又一个漂亮不变现的故事。
3. **冷启动**:agent 还没聪明前,第一天凭什么用?→ **回路本身必须在没有 agent 时就独立值得用** 【假设·未证】。

### 6. 战略岔路（要 owner 亲自拍,别糊)

**同一个回路,两种 pitch + 两种获客:**
- **A · 广**:"给读者的**留存工具**"——你读的东西终于留得住。TAM 大、门槛低、天花板小而美。
- **B · 窄**:"给**高风险决策者**的判断捕获"——为你下一个查不到答案的硬判断服务。人群窄、更锋利、更贵、更可能有人真付钱(接第四块问题2)。

**必须先选一个当主叙事**——它决定 MVP 的措辞、找谁验证、以及第一批客户是谁。**别在中间站着**(既想当读者工具、又想当决策者工具,两头不占)。

## 结论

**果断的一句**:LOOM 是"当 AI 让执行免费,把你唯一抄不走的东西——判断力——费力逼出、攒成你的数据、长成你的 agent"的地方。这个方向**足够大、也足够真**。

**诚实的一句**:但它今天**没有能力护城河**,靠的是"自律 + 数据"这层软 harness;它的**生死取决于两件都还没证的事**——(1)回路能不能真把判断逼成比 memory 更值钱的数据;(2)有没有一个"很快要为硬判断负责、又查不到答案的人"愿意为它付钱。**其余都还是话。**

**立刻要做的一件事**:不是建,是**验证**——5–10 个 forcing-function 用户,零代码,看留存。同时 owner 拍下第 6 条那个岔路(A 还是 B)。
