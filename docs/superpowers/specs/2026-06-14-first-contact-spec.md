# LOOM「初次靠近 / First Contact」— Digital Me 头盔交互 · 实现规格

> 交付对象:Codex(或任何实现者)。本文件在 LOOM 仓库**之外**,不影响仓库。
> 版本:v1 · 2026-06-14 · 设计方向已与 Yiping 逐条确认。

---

## 0 · 一句话概念

纯黑里**「History」大标题居中、闪几下后熄灭(冷开场)** → Digital Me 在冰冷黑暗中远远沉睡 → 触发后**缓缓靠近、转向你** → 贴到最近时**整个世界涌起彩色 + 丁达尔光束 + 月球盈满 + 面罩浮现 LOOM 与释义**(LOOM 由 ① 均匀经**彗星划过**长成 ② **M 放大**全彩) → 随后**彩色退回冷黑**,只留 LOOM 亮在面罩上。

气质:宏大、史诗、克制。全站 95% 是冷黑 + 青的极简,**唯一一次色彩涌起只在这一刻**——正因稀有才珍贵。

**含义**:散落冰冷的数据(黑白、远) → 一个温暖、在场、活着、能替你回答的身份(全彩、近、开口)。头盔 = 被你的知识构成的"代表自我";月球 = 记忆(既是 Digital Me 个人记忆,也是人类几千年对月的追寻——最古老的集体记忆)。自我向前走近你,记忆在它身后盈满、被照亮——因为这个自我正建立在那片记忆之上。

## 1 · 进度模型(让一切协同)

- 用一个归一化进度 `p ∈ [0,1]` 驱动**全部**:头盔 scale/位移、调色饱和度、光束强度、月相、文字 reveal。
- **触发**(推荐):`p` 由**滚动进入视区**scrub 驱动(section 进入 → `p` 0→1)。可改为 hover / 点击触发后自动播一次。
- 到 `p=1` 触发一次性**高潮 timeline**,随后 **settle**(彩色/光束淡出,LOOM 留)。
- **指针移动**单独驱动:面罩高光视差、曲面文字 rotateY 视差、触碰涟漪(与 `p` 无关,任何时候可交互)。

## 2 · 编排(choreography)

**Act 0 · 开场(Cold Open · 一次性 · 在 S0 之前)**:纯冷黑,**「History」衬线大标题居中**(Fraunces,呼应页面 display),静置 ~2–3s 呼吸 → **轻微闪烁几次**(像信号/记忆忽明忽暗,不规则、克制,≤3 次)→ **熄灭/淡出** → 镜头从黑里升起,进入 S0。含义:History(记忆)像一段信号忽闪,然后让位给"活的"场景。
**闪烁安全(必守)**:克制——**绝非全屏高对比频闪**(光敏 / WCAG 2.3.1 风险);低对比、小范围、≤3 次忽明忽暗。**只在同会话首次播一次**(用 sessionStorage 标记,之后直接进 S0,别每次都等)。`prefers-reduced-motion` → 跳过闪烁,History 静置后直接淡出或直接进场。首屏/SSR 不阻塞。

| 态 | p | 头盔 | 调色 | 月球 | 面罩 |
|---|---|---|---|---|---|
| **S0 静止** | 0 | 远、小、半入阴影,仅一道冷边光(月牙状) | 纯黑白 | 冷残月,远,清晰 | 全黑沉睡 |
| **S1 靠近** | 0→1 | 平滑放大 + 转向,从阴影浮出,边光变宽 | 仍黑白,边缘渗第一缕暖 | 渐盈;开始柔焦后撤(见 §4) | 浮起青色知识点(微) |
| **S2 抵达·高潮** | 1 (burst) | 贴近、半裁、占住画面、聚焦锐利 | **黑白→全彩(随彗尾苏醒)** + 丁达尔光束 | 彗星划过点燃 → **盈满 + 变亮、宏大散景** | LOOM 先 ① 均匀单色 → **彗星从 M 划向月** → **② M 放大 + 全彩**;释义沿曲面浮现 |
| **S3 归位** | 1 (settled) | 留近景 | 彩色/光束淡出,回冷黑 | 回冷调(可留满,降亮) | 只剩 LOOM 亮在曲面玻璃上 |

**时序参考**
- 靠近:1.8–2.4s ease-out(或纯 scroll-scrub)
- 高潮 burst:~0.9s(饱和涌起 + 光束淡入 + 月盈满 + 高光归位 + 焦点拉到头盔)
- reveal:LOOM 字标 ~0.6s 浮现 → 释义 ~0.5s 错峰(沿曲面从中心向两侧点亮)
- 归位:彩色 + 光束 ~1.2s ease 淡出,LOOM 留

## 3 · 图层结构(z 由后到前)

1. **背景**:冷黑 `#07090C` + vignette;**丁达尔光束层**(高潮才显)
2. **月球**(后方偏左):月相补间 + 焦点/亮度变化
3. **头盔组**
   - 外壳 / 轮廓(真实图压暗,或 SVG 蒙版轮廓)
   - 边缘弧光(主光,左上;= 月牙那道光)
   - **面罩**(嵌套子层,由后到前):
     1. 玻璃底(深黑曲面)
     2. 反射层(知识星座 + 高潮的全彩宇宙)
     3. 内容层(LOOM 字标 + 释义,**曲面文字**,见 §6)
     4. 斜向高光扫光(压在内容之上 → 内容"在玻璃下")
     5. 触碰涟漪层
4. **前景微尘**(给丁达尔光束体积感)

## 4 · 月球的纵深行为(关键:别缩小)

- **不要让月球缩小退远**——会读成"月亮在逃",且记忆不该在自我到来时退场。
- 让位靠**视差 + 让焦**,不靠变小:
  - **视差**:头盔(前景)快速变大 + 上移/前推;月球(远景)几乎不缩,只**极缓反向漂移一点**。速率拉开 → 3D 分层。
  - **rack focus(最电影)**:靠近时月球清晰在场;头盔贴近、彩色涌起时,**焦点拉到头盔(锐利),月球柔成宏大散景(bokeh)** + 同时**盈满、变亮**。"后撤感"来自虚化与让焦。
- 高潮时月球**更宏大**:盈满、被暖光/丁达尔扫亮,作为"已抵达自我"身后那轮完整的记忆。
- (若仍想要物理退远:只给**极轻微**缩小 + 漂移,幅度小到"沉静后撤"而非"逃走"。默认不缩。)

## 5 · 特效机制

- **黑白 → 彩色 grade**:全局 `saturate()` + 色温由 `p` 驱动(0→1→0)。最稳做法:彩色层(面罩反射宇宙、光束暖色)平时 `filter: grayscale(1) brightness(.7)`,高潮 cross-fade 到 `grayscale(0)`,归位再回。色彩要**有动机、摄影感**:暖白/琥珀(日出)+ 地球蓝绿 + 青——**不是饱和 UI 彩虹 / disco**。**注意**:彩色的苏醒由下面的"彗星催化"驱动(色彩在彗尾里被点亮),不是全局突然亮。
- **丁达尔光束(volumetric / god-rays)**:单一光源(左上),3–5 道 `linear-gradient` 光柱 + `blur` + `mix-blend-mode: screen`,低透明度;高潮淡入,随指针轻微摆。是柔光柱,不是激光。
- **月相**:残 → 满,用蒙版/终止线阴影形状补间(平滑,非跳变);高潮时青色终止线那道缝可整条点亮(被彗星点燃)。
- **彗星催化(高潮的点火 · 关键)**:高潮瞬间,一颗**单一细彗星**(亮头 + 渐细发光尾,白/青)**从 LOOM 的 M 顶点划出、优雅弧向月亮**(正是被拿掉的那条"线够月"的轨迹——此处以一次性运动复活,过后消散,所以静态字标始终干净)。彗星驱动三件事**同步**发生:① **色彩在彗尾里苏醒**(沿彗星路径的渐变蒙版揭开彩色层——彗星"画"出彩色,而非全局闪);② **月球终止线缝被点燃**、随之盈满变亮;③ **字标从 ① 均匀 补间到 ② M 放大**(M=Memory 壮大)。彗星没入月亮/消散后,留 ② 全彩 LOOM,再随归位退回冷黑。时长 ~1.2–1.8s,弧线优雅(非直线疾射),克制。做法:canvas/WebGL 沿 path 运动 + 跟随的色彩揭示蒙版;或 SVG `<animateMotion>` + 沿路径的渐变 mask。**含义**:一束记忆之光从 M 飞向月亮,沿途唤醒色彩与记忆。

## 6 · 面罩文字的曲面感(史诗关键)

文字必须**贴合外凸曲面**,面罩才成为一块巨大弧形屏(IMAX / 天象厅 / 座舱 HUD 的宏大),而非平贴。

- **基线外凸弧**:LOOM 字标 + 释义行用 SVG `<textPath>` 贴在外凸 path 上(向你鼓出)。中间字最大最近,越向两侧越收。
- **边缘衰减(比弧线更卖曲面)**:逐字 `opacity` + `scale` 向两侧递减,边缘字略 `rotateY` 转走 + 轻微失焦(景深)。
- **在玻璃之下**:斜向高光扫光与反射层**压在文字之上**,文字才像嵌在玻璃里;反射的色微染到字上。
- **指针视差(最强 3D 提示)**:指针移动时整块曲面文字随之**轻微 rotateY 摆动**(面罩在"转面")。`perspective()` + 小角度 `rotateY`。
- **沿曲面 reveal**:高潮时文字**从中心向两侧沿弧线点亮/打字**,强化"巨幕亮起"。
- **史诗尺度**:高潮时文字做大、弧、被光打亮;归位后收成更安静的状态。

**做法(由轻到重)**
1. 轻(够用且性能好):SVG `<textPath>` 弧基线 + 逐字 opacity/scale 衰减 + CSS `perspective()/rotateX()` 把整块字放到面罩斜面 + 指针 `rotateY` 视差。
2. 重(最史诗):面罩内容渲成纹理、WebGL 贴到**弧面 mesh**——真曲率 + 真视差 + 真景深。太重则退化为预渲染序列。

## 7 · 面罩内容(高潮浮现 · 已定)

- **LOOM 字标**:**Fraunces 衬线**(serif,有灵魂/史诗气),干净排版。**① 均匀 和 ② M 放大(Memory)都要**——它们是高潮彗星动画的**首尾两帧**(① 起 → 彗星划过 → ② 终,见 §5 彗星催化)。**静态字标里不要常驻的线/月**(那条"线够月"只作为一次性彗星出现);月亮只常驻在 app 图标里。超小尺寸(favicon/导航/远处面罩)配一套无衬线/mono 作伴。**不要用 Space Grotesk。**
- **释义(已锁)**:面罩高潮显示 ——
  - eyebrow(小,弧基线,可选):`LIBRARY · EYES · MEMORY`
  - 主释义行:`A living, source-backed identity that can answer for you`
    - 中文语境页可换:`一个有据、活着、能替你回答的知识身份`
  - 英文为主(契合面罩 HUD / 遥测 / SpaceX 的电影气质,与 wordmark、`SOURCE-BACKED IDENTITY` 同语言)。

## 8 · 触碰 / 指针交互

指针按下或移动到玻璃 → **一圈极克制涟漪 + 接触点局部高光晕开**(~0.4s 淡出),最近的几个星座点短暂亮起;光标在玻璃上留**微弱拖尾光**。**不要水花感。**

---

## 9 · 兜底(关键,别做碎)

`prefers-reduced-motion` / 无 JS / 首屏(SSR)→ 直接渲染 **S3 静态帧**:头盔近景 + 面罩上 LOOM + 释义(**保留曲面文字的弧基线 + 边缘衰减静态感**)+ 冷黑 + 月可留满(冷调)。永不空、不碎、不依赖动画。靠近 + 彩色涌起只是渐进增强。

---

## 10 · 性能

- 靠近只用 `transform / opacity`(GPU 合成)。
- 高潮的 grade / 光束限制在少数层的 `opacity / filter`。
- `IntersectionObserver` 近视区才初始化,离开即暂停。
- 尊重 `prefers-reduced-data`。
- 整体太重 → 退化为**预渲染序列 / 视频**做 hero,交互层(涟漪/视差)再叠加。

## 11 · 实现建议(各层怎么做)

- **头盔**:优先用一张真实渲染/摄影头盔图**压暗**做底(真实感最高),边缘弧光 + 面罩内容用叠加层;轮廓可用 SVG 蒙版。纯矢量轮廓是退路。
- **反射宇宙层**:一张低透明度的地球夜面 / 星点图,平时灰度、高潮上色——比纯手绘星座更真。
- **月球**:真实月球图(已有于 History 页素材),月相用蒙版补间;焦点用 `filter: blur()` 在高潮拉起(散景)。
- **曲面文字**:见 §6,优先方案 1。

## 12.5 · App 图标(3D 月球建模 · 已定 2026-06-14)

图标 = **真 3D 建模的月球**(不是平面贴图叠效果,也不是写实照片——照片对 app 图标"太真实"):
- **建模**:Three.js 球体 + 等距柱状(equirectangular)月面**色图 + 位移/凹凸图**(真环形山起伏)+ **正交相机**(规整圆盘、无透视畸变)。
- **光**:单一**强侧光**(左上)+ 极低冷调环境光 → **盈凸晨昏线 + 环形山长影**从真实光照里长出;暗侧极暗(可加一丝地球反照微光更高级)。
- **合成**:深空冷黑 squircle(Apple 圆角 ≈ 0.2255×边长)+ 圆月居中(直径 ~0.72)+ 冷调 + 暗角 + 顶左 rim 光 + 背后极淡青/氛围辉光。
- **青色 = 月球的光(不是线)· 已定 variant C**:暗侧(阴影一缘)一道**青色日冕/边光**(`#4BC5DE` + `#8AF7E6` 亮芯,沿暗缘弧;限内一圈、限外一圈轻微外溢到深空)+ **极淡青色背景辉光**(偏阴影侧、`screen`、低 alpha)+ 暗侧极faint青色环境填充。**不要画线/终止线缝**——青色是背照/反射的光感。全图唯一颜色;此处理从 1024 到 40px 都成立(日冕小尺寸仍可见,作品牌信号)。
- **尺寸**:出全尺寸(1024…16)`.icns`(`macos-app/Loom/Assets.xcassets/AppIcon.appiconset`)+ web `favicon`/`apple-touch-icon`。
- **贴图许可**:预览用 Solar System Scope(CC BY 4.0);**上线换 NASA CGI Moon Kit 公有领域色图 + 位移图**(PD,真位移、可商用)。
- **同源**:这枚月 = 字标里"M 够月"的那枚 / 彗星的归宿 / Digital Me 的记忆——字标、图标、交互一套语言。
- **安装**:替换当前 `loom_lunar_comet_icon` 与 `AppIcon.appiconset`,留到能写入仓库(Codex 停)+ 生产 pass 执行。
- **复现**:用 Playwright 跑 Three.js 离屏渲染(`--use-angle=swiftshader`)→ 截帧 → 2D canvas 合成 squircle/青缝/调色 → 导出各尺寸。

## 13 · 决策(已全部锁定 · 2026-06-14)

1. **触发方式** → **滚动进入视区**(scroll-into-view scrub 驱动 `p`)+ 指针驱动高光/涟漪/曲面视差。
2. **头盔素材** → **真实头盔图压暗**做底,边缘弧光 + 面罩内容用叠加层。
3. **面罩释义** → 见 §7:英文为主 `A living, source-backed identity that can answer for you`,可选 eyebrow `LIBRARY · EYES · MEMORY`。
4. **月球纵深** → **不缩**;仅视差 + rack focus 让焦 + 高潮盈满变亮宏大(见 §4)。

## 14 · 一句话给 Codex

把 History 页右侧那块"HUD 屏"升级成**一个从黑暗中靠近的宇航员头盔**:静止时远而暗(只一道冷边光),滚动靠近时变大转向,贴到最近瞬间**黑白涌成全彩 + 丁达尔光束 + 月球盈满变宏大 + 曲面文字浮现 LOOM 与释义**,随后**退回冷黑**只留 LOOM。全程单一左上主光、冷黑克制,彩色只此一次。务必给 reduced-motion / 首屏一个**静态"已抵达"兜底帧**。
