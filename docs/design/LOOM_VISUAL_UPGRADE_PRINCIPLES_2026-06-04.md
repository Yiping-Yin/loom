# Loom Visual Upgrade Principles

Status: active design direction
Date: 2026-06-04
Scope: homepage, Loom history, Education, Experience, Digital Me, and source-backed section pages

This note separates what should be learned from the early Loom version from what should not be copied.

## The Early Version Is A Source, Not A Skin

Do not imitate the early Loom version as a black theme, manifesto page, or decorative brand treatment.

Use it as evidence for the product's strongest design principles:

- One coherent atmosphere should govern the whole page.
- The screen should feel composed before it explains itself.
- Text should be sparse, precise, and placed with rhythm.
- Source material should remain visible without becoming a file-browser dump.
- Thin rules, large negative space, and restrained contrast should create structure.
- The interface should feel like a reading-and-thinking environment, not a dashboard.
- Product meaning should drive visual choices; decoration should be removed.

## Current Product Direction

The current Loom surface must combine two things:

- Early Loom's discipline: atmosphere, tension, restraint, and source-bound thinking.
- Current Loom's truth: real profile, education, experience, certificates, coursework, projects, and Digital Me evidence.

The goal is not "early Loom, but with photos." The goal is a mature identity-and-knowledge product that can show real material without losing visual control.

## Practical Rules

1. Build a complete first viewport before adding more sections.
2. Prefer one strong visual system over many visible UI modules.
3. Use real assets only when they are cropped, framed, and toned intentionally.
4. Do not let logos, PDFs, screenshots, or file names create accidental composition.
5. Keep section copy short enough that the assets and hierarchy explain the page.
6. Avoid dashboard language on public-facing identity pages.
7. Avoid raw portfolio-card grids unless the grid itself carries meaning.
8. Each page should have a single dominant visual idea.

## Page Implications

Homepage:
Use Yiping as the first reference instance. The page should feel like a controlled identity atlas, not a file shelf.

Loom history:
Show the early version as provenance and product thesis. Keep it clearly separate from the current reference instance.

Education:
Show courses, certificates, and learning outputs as a source-backed learning path. Avoid turning the page into a list of school logos.

Experience:
Show projects, work, competitions, and build records through visible artifacts and process evidence, not generic resume cards.

Digital Me:
Show capability through answer, citation, canvas, and process states. It should not be only an ask box.

## Review Question

Before accepting any Loom page, ask:

Does this screen feel like real source-bound identity and thinking made visible, or does it only arrange assets with labels?
