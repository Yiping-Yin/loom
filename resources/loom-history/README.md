# Loom History Resources

This folder preserves source/reference copies of Loom history assets.

Served app copies live in `public/loom/history/`. Do not treat `public` as the
source archive.

## Sets

- `early-version/`: uploaded screenshots from early Loom concept and product
  exploration work.
- `evolution/`: representative checkpoints selected from later iterations and
  promoted into the product-history route.

## Rules

1. Add historical assets here first.
2. Copy only selected public-facing assets into `public/loom/history/`.
3. Keep generated screenshots and bulk verification output in `archive/screenshots/`.
4. Promote representative assets intentionally; do not expose every iteration.
5. Update `docs/design/LOOM_EVOLUTION_INTEGRATION_MAP_2026-06-04.md` when a new
   historical set changes the product interpretation.
